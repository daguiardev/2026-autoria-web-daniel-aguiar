Como Utilizar o Template

Visão Geral

Este documento é um arquivo HTML estático. Para criar novos slides, basta duplicar as tags <section> que possuem a classe slide.

Estrutura Básica

Cada slide deve possuir um id sequencial (ex: slide-3, slide-4). A transição é controlada pelo JavaScript no final do arquivo.

Estilização com Tailwind

Todo o layout é feito com classes utilitárias do Tailwind CSS. Cores padrão: fundos em slate-900/800 e destaques em emerald-400.

Layouts Pré-configurados

Organizando o Conteúdo

A estrutura de duas colunas é ideal para contrastar conceitos, comparar ideias ou apresentar um texto ao lado de um bloco de código/imagem.

  • Utiliza grid grid-cols-2 do Tailwind.
  • O espaçamento interno é garantido pelo gap-12.
  • Perfeito para exemplos práticos.

Caixa de Destaque

Este é um bloco de atenção. Pode ser usado para regras de negócio, avisos importantes ou resultados esperados. 
<div class="grid grid-cols-2 gap-12">
    <!-- Coluna Esquerda -->
    <div>...</div>
    <!-- Coluna Direita -->
    <div>...</div>
</div>

Mosaico de Cards

Layouts Pré-configurados

Tópico Inicial

Este layout usa grid-cols-3. Útil para apresentar características de um sistema, fases de um projeto ou agendas detalhadas.

Desenvolvimento

Cada card se ajusta automaticamente ao espaço disponível. Ícones do FontAwesome facilitam a leitura visual.

Atenção (Variante)

Você pode facilmente alterar a cor base do card de verde (emerald) para amarelo (amber) para denotar avisos ou erros.
