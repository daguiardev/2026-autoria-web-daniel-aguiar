## Como clonar este repositório
1. Abra o terminal ou prompt de comando na sua máquina.
2. Navegue até a pasta onde deseja clonar o repositório:
   ```bash
   cd /caminho/para/sua/pasta
   ```
3. Execute o comando de clone usando a URL do repositório:
   ```bash
   git clone https://github.com/daguiardev/2026-autoria-web-daniel-aguiar.git
   ```
4. Acesse a pasta do projeto clonada:
   ```bash
   cd 2026-autoria-web-daniel-aguiar
   ```
5. Pronto! Agora você tem o repositório em sua máquina local e pode começar a trabalhar.
